# Fret & Flow — ห้องฝึกกีตาร์ของน้องนัด

เว็บภาษาไทยสำหรับค่อย ๆ สร้างพื้นฐานฟิงเกอร์สไตล์ ตั้งแต่จำโน้ตบนคอกีตาร์ ดูรูปจับคอร์ด ฝึกฟังเสียง ไปจนถึงแยกเบสกับเมโลดี้เป็นจังหวะ ใช้การตั้งสายมาตรฐาน **E2 A2 D3 G3 B3 E4** จากสาย 6 ไปสาย 1

แอปใช้ HTML, CSS และ JavaScript modules ไม่มีขั้นตอน build และไม่มีแพ็กเกจที่ต้องติดตั้งเพื่อเริ่มใช้งาน

## เปิดใช้งาน

### ทางเลือก 1: เซิร์ฟเวอร์ที่ให้มา

ติดตั้ง Node.js 18 ขึ้นไป แล้วเปิด Terminal ในโฟลเดอร์โปรเจกต์:

```text
npm start
```

เปิด **http://127.0.0.1:4173** ในเบราว์เซอร์ เซิร์ฟเวอร์รับการเชื่อมต่อจากเครื่องนี้เท่านั้น กด `Ctrl+C` เพื่อปิด

### ทางเลือก 2: Laragon

วางโฟลเดอร์ไว้ในโฟลเดอร์เว็บของ Laragon เปิดเว็บเซิร์ฟเวอร์ แล้วเข้า **http://localhost/Guitar-tran/** ชื่อพาธต้องตรงกับชื่อโฟลเดอร์จริง หากใช้โดเมนท้องถิ่น เช่น `guitar-tran.test` ให้ใช้ HTTPS เมื่อต้องการเปิดไมโครโฟน

### ทางเลือก 3: Live Server

เปิดโฟลเดอร์โปรเจกต์ในตัวแก้ไขที่มี Live Server แล้วเปิด `index.html` ผ่านเซิร์ฟเวอร์ ใช้ที่อยู่ `http://localhost:…` หรือ `http://127.0.0.1:…` ตามที่เซิร์ฟเวอร์แจ้ง

ควรเปิดผ่านเว็บเซิร์ฟเวอร์เสมอ การดับเบิลคลิกไฟล์เป็น `file://` อาจทำให้ JavaScript modules โหลดไม่ได้

## ห้องฝึกทั้ง 6 หน้า

| หน้า | ใช้ฝึกอะไร |
| --- | --- |
| ภาพรวม | ดูกิจกรรมประจำวัน เวลาฝึก ความแม่นยำ และทางลัดไปห้องฝึก |
| โน้ตบนคอกีตาร์ | แตะฟังโน้ต เลือกสายและช่วงเฟรต ฝึกหาตำแหน่งหรือทายชื่อโน้ต และลองตอบด้วยเสียงผ่านไมค์ |
| คอร์ด | ค้นหาคอร์ด กรองชนิดและรูปจับ ดูนิ้ว สายเปิดและสายที่ไม่ดีด ฟังทั้งคอร์ดหรือแยกทีละสาย และฝึกวงคอร์ด |
| ฝึกฟัง | ทายชื่อโน้ตในช่วง C4–B4 หรือระยะคู่เสียง พร้อมเสียงอ้างอิง C4 และโน้ตธรรมชาติ |
| ฟิงเกอร์สไตล์ | อ่าน TAB กับนิ้ว P/I/M/A ฝึกอาร์เพจจิโอ เบสสลับแบบ Travis จังหวะ 6/8 และเบสพร้อมเมโลดี้ ปรับความเร็ว นับเข้า และเล่นวนได้ |
| ตั้งสาย | ฟังเสียงอ้างอิงของสายเปิด หรือใช้ไมโครโฟนดูชื่อโน้ต ความถี่ และความคลาดเคลื่อนเป็นเซนต์ |

มีเมโทรนอม 4/4 สำหรับฝึกจังหวะทั่วไปด้วย ส่วนห้องฟิงเกอร์สไตล์มีเมโทรนอมของตัวเอง: หนึ่งคลิกคือโน้ตดำใน 4/4 และโน้ตดำประจุดใน 6/8

## เริ่มฝึกอย่างไรดี

1. ตั้งสายให้ใกล้เคียงก่อน โดยดีดทีละสายและลดเสียงรบกวนรอบตัว
2. เริ่มจำโน้ตสายเดียว เฟรต 0–3 แล้วขยายเป็น 0–5 และ 0–12 เมื่อคล่อง
3. ดูคอร์ด C, Am, F และ G ฝึกจับแล้วดีดทีละสายให้เสียงใส
4. เปิดฟิงเกอร์สไตล์ที่ 50–72 BPM ฟังหนึ่งวลีก่อน แล้วลองเล่นตามให้ครบ 4 ห้อง
5. เพิ่มความเร็วครั้งละ 5 BPM เมื่อเปลี่ยนคอร์ดและแยกนิ้วได้สม่ำเสมอ

ใน TAB สาย 1 อยู่ด้านบน สาย 6 อยู่ด้านล่าง ตัวเลขคือเฟรตที่กด และ `0` คือสายเปิด นิ้วขวา `P` คือโป้ง `I` คือชี้ `M` คือกลาง และ `A` คือนาง

## เสียงและไมโครโฟน

- กดปุ่มฟังหรือเริ่มฝึกเพื่อเปิดระบบเสียงก่อน เบราว์เซอร์อาจระงับเสียงจนกว่าจะมีการกดของผู้ใช้
- เสียงตัวอย่างเป็น **เสียงสังเคราะห์ด้วย Web Audio** สำหรับอ้างอิงระดับเสียงและจังหวะ ไม่ใช่เสียงนักกีตาร์ที่บันทึกไว้
- ไมโครโฟนต้องใช้ **HTTPS หรือ localhost/127.0.0.1** และต้องอนุญาตสิทธิ์ในเบราว์เซอร์ โดเมนท้องถิ่นแบบ HTTP อาจเปิดไมค์ไม่ได้
- เสียงไมค์ประมวลผลในเบราว์เซอร์บนเครื่อง ไม่มีการอัปโหลดหรือบันทึกไฟล์เสียงส่งออกไปยังเซิร์ฟเวอร์
- ตัวตรวจจับออกแบบมาสำหรับโน้ตเดี่ยว ควรดีดทีละสาย รอให้เสียงนิ่ง และใช้หูฟังเมื่อฟังเสียงตัวอย่างเพื่อลดเสียงลำโพงย้อนเข้าไมค์
- ไมค์ตรวจได้ว่าระดับเสียงตรงกับโน้ตเป้าหมายหรือไม่ แต่ระบุไม่ได้ว่าเล่นจากสายหรือเฟรตใด และไม่ได้ตรวจท่าจับมือ
- รอบฝึกฟิงเกอร์สไตล์นับเมื่อเครื่องเล่นเดินครบหนึ่งวลี 4 ห้อง ยังไม่ได้ประเมินว่าผู้ใช้เล่นตามถูกต้องผ่านไมโครโฟน
- เมื่อเปลี่ยนหน้าหรือซ่อนแท็บ การฝึกที่มีจังหวะจะหยุดหรือพักอัตโนมัติ กลับมาแล้วกดเริ่มหรือฝึกต่ออีกครั้ง

## ความก้าวหน้าถูกเก็บที่ไหน

ข้อมูลกิจกรรม คำตอบ ประวัติล่าสุด และตัวเลือกการฝึกเก็บด้วย `localStorage` ในเบราว์เซอร์ของเครื่องนี้ โดยใช้คีย์ `fret-flow-v2` ไม่มีระบบบัญชีหรือการซิงก์ข้ามเครื่อง

ข้อมูลผูกกับ **origin เดิม** ได้แก่โปรโตคอล ชื่อโฮสต์ และพอร์ต ตัวอย่างเช่น `localhost:4173` กับ `127.0.0.1:4173` หรือ Live Server คนละพอร์ต จะมีความก้าวหน้าแยกกัน การล้างข้อมูลเว็บไซต์ เปลี่ยนเบราว์เซอร์ หรือออกจากโหมดไม่ระบุตัวตนอาจทำให้ข้อมูลเดิมหายไป

## ตรวจสอบโปรเจกต์

```text
npm test
```

การทดสอบอัตโนมัติครอบคลุมตรรกะดนตรี การตรวจจับระดับเสียง การเปิดและปิดไมโครโฟน และการเก็บความก้าวหน้า ควรทดลองเสียง ไมโครโฟน และรูปแบบหน้าจอในเบราว์เซอร์จริงด้วย

ไฟล์ **`legacy-trainer.html`** คือสำเนาเว็บเดิมก่อนอัปเกรด เก็บไว้สำหรับอ้างอิงและย้อนดูพฤติกรรมเดิม
